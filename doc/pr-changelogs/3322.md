 * add `AllowCombinedMapRendering` boolean config (default false): with deferred map rendering enabled, the ground is rasterized only once. The deferred pass also produces the lit forward color, which is composited to the screen instead of drawing the mesh a second time. Trade-offs: ground-interior pixels are not multi-sampled (unit/feature silhouettes keep their MSAA) and the G-buffer diffuse contains the on-screen result, info-texture overlay included.
 * `Spring.SetMapShader(standardID, deferredID, combinedShader)` gains an optional third argument declaring that the deferred program also writes the lit forward color to fragment output 5 (non-zero alpha where opaque), making the shader eligible for the combined pass.
 * `DrawGroundPreForward` does not fire while the combined pass is active, since there is no forward mesh pass to set up.
