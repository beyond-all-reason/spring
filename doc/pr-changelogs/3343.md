* add configfloat `ProjectileShadowMinPixels` (default `2`): model-less particles whose draw radius covers fewer than this many screen pixels do not cast transparent shadows; 0 lets every shadow-casting particle cast one.
* Engine-spawned smoke puffs (damaged-unit `SFX_WHITE_SMOKE`/`SFX_BLACK_SMOKE`, burning wreck smoke, the default aircraft engine trail and wreck trails) no longer cast shadows. CEG-defined and Lua-spawned projectiles (including the `castshadow` tag) and geothermal vent smoke are unaffected.
